# FixLab 3D

កម្មវិធីគេហទំព័រសម្រាប់ស្វែងយល់ពីទូរស័ព្ទ 3D, វិនិច្ឆ័យបញ្ហា, អានមគ្គុទ្ទេសក៍ជួសជុល និងស្វែងរកគ្រឿងបន្លាស់។

## ដំណើរការ

```bash
npm install
npm run dev
```

បើក URL ដែល Vite បង្ហាញ។ សម្រាប់ production ប្រើ `npm run build`។

## មុខងារ

- ម៉ូដែលទូរស័ព្ទ 3D បង្វិល ពង្រីក និងបំបែកគ្រឿងបង្គំ
- វិនិច្ឆ័យរោគសញ្ញា និងណែនាំគ្រឿងបន្លាស់
- មគ្គុទ្ទេសក៍ជួសជុលតាមជំហាន
- ស្វែងរក តម្រៀប និងបន្ថែមគ្រឿងបន្លាស់ក្នុងកន្ត្រក
- ទម្រង់សាកល្បងសម្រាប់កក់សេវា និងស្នើសុំបញ្ជាទិញ

**ចំណាំ:** ទិន្នន័យផលិតផល និងសំណើកក់/បញ្ជាទិញជាទិន្នន័យសាកល្បងនៅក្នុង browser ប៉ុណ្ណោះ។ មិនមាន backend ឬការទូទាត់ពិតប្រាកដទេ។
